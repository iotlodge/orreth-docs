Kernel 0.1.0 is configured by environment variables — **dials** — read by the kernel, the
reference and the bodies. Most have a standing default that stands a world on one machine; the
[first-world compose file](/build/first-world/) sets the handful that differ inside a box. A dial
declared as a governed value a person turns from the glass (the first architecture's thirty-six
dials) is re-seated in this architecture and not yet built.

Provider keys — `ANTHROPIC_API_KEY`, `OPENROUTER_API_KEY`, `OPENAI_API_KEY` — are not dials of
Orreth's: their *values* are read by the gateway alone, and the kernel checks only that a key's
*name* is reachable where it stands before it registers a mind that needs it (the env-secrets
law: a key value lives in no record and no file of Orreth's).

## Where the values were read

This table was collected by hand from the code that reads each dial — the kernel crate
(`backend/plane/crates/orreth-spine/src`), the reference (`spine/orreth_spine`), the rig
(`scripts/dev.sh`), the compose file and the Dockerfile — at kernel 0.1.0. When a dial moves, the
table moves with the release.
